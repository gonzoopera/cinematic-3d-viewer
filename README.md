# 🎬 Cinematic 3D Viewer (React + Three.js)

A lightweight, highly customizable React component for rendering 3D models with professional, high-contrast cinematic lighting setups. Built on top of Three.js and React Three Fiber.

## 🌟 Why this project?
Standard 3D viewers often lack the aesthetic polish required for modern web design. This open-source library provides pre-configured editorial and cinematic lighting environments, allowing front-end developers to showcase products or art with studio-quality rendering directly in the browser.

## 🚀 Features
- **Pre-built Lighting Rigs:** Studio, Neon Cyberpunk, and High-Contrast Editorial.
- **Optimized Performance:** Lazy loading and geometry compression out of the box.
- **Post-Processing Ready:** Built-in hooks for adding WebGL film grain, bloom, and color grading.

## 📦 Installation
\`\`\`bash
npm install cinematic-3d-viewer
\`\`\`

## 🛠️ Tech Stack

- Three.js / WebGL
- React Three Fiber / Drei
